# AETHERIA | CONTINUUM

**Proyecto principal de investigación de Gianina Jensen Guzmán**

AETHERIA | CONTINUUM es un proyecto independiente de investigación computacional orientado a explorar preguntas sobre causalidad y estructura del espacio-tiempo. Combina formulación de hipótesis, experimentación y análisis de información. Se encuentra en desarrollo.
