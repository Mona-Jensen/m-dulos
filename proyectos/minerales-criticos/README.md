# Minerales críticos de Chile

Prototipo de consulta y representación cartográfica de depósitos y sus atributos.

**Autoría:** Gianina Jensen Guzmán.

## Qué incluye

- Interfaz HTML y dos colecciones GeoJSON.
- Representación de ubicaciones y atributos de depósitos.

## Tecnologías

HTML, JavaScript y GeoJSON.

## Estado de la muestra

Prototipo independiente.

## Ejecución

```text
python -m http.server 8080
```

## Alcance y pendientes

Las colecciones pasan validación JSON; su procedencia y actualización no están verificadas. No se presenta como plataforma del Gobierno de Chile.
