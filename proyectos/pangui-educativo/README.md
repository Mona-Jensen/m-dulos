# Pangui educativo

Acercar contenidos educativos a la infancia mediante un cuento ilustrado e interacción digital.

## Autoría

Proyecto creado y desarrollado individualmente por Gianina Jensen Guzmán.

## Qué incluye

Cuento de cinco escenas, imágenes, video introductorio y selector inicial de idiomas.

## Estado

Prototipo en desarrollo.

## Tecnologías

React, TypeScript, i18next y Vite

## Ejecución

```text
npm ci
npm run dev
```

Las instrucciones se deducen de los archivos; no implican una ejecución validada en este entorno.

## Alcance y limitaciones

El cuento permanece en español. Faltan audios e imagen de huella referenciados. El enfoque inclusivo es un objetivo y no una validación de accesibilidad o eficacia pedagógica.
