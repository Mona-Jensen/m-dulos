# Cronos 3D

Explorar contenidos sobre la historia geológica de la Tierra mediante una interfaz tridimensional.

## Autoría

Proyecto creado y desarrollado individualmente por Gianina Jensen Guzmán.

## Qué incluye

Selección de etapas geológicas, vista 3D y paneles de información.

## Estado

Prototipo educativo.

## Tecnologías

React, TypeScript, Three.js y Vite

## Ejecución

```text
npm ci
npm run dev
```

Las instrucciones se deducen de los archivos; no implican una ejecución validada en este entorno.

## Alcance y limitaciones

Representación ilustrativa; no es una reconstrucción paleogeográfica validada. Los contenidos científicos requieren revisión editorial.
