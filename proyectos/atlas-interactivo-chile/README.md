# Atlas Interactivo de Chile para PC

Muestra de una aplicación de escritorio sobre Chile entregada como compilación de Windows.

**Autoría:** Gianina Jensen Guzmán.

## Qué incluye

- Paquete ejecutable y archivos de datos de la aplicación.
- Inventario y huellas SHA-256 del material recibido.

## Tecnologías

Compilación Windows con estructura de Unity.

## Estado de la muestra

Aplicación compilada recibida; no ejecutada en este entorno Linux.

## Alcance y pendientes

El paquete no incluye el proyecto fuente. No se publica el ejecutable ni sus recursos masivos en Git. Falta validar funcionamiento en Windows, autoría de recursos y condiciones de distribución.
