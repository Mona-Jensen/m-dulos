# Propuesta de plataforma web 2027

Paquete conceptual de planificación de un sitio web.

**Autoría:** Gianina Jensen Guzmán.

## Qué incluye

- Presentación ejecutiva, memoria y wireframes descriptivos.
- Mapa de navegación y plan de implementación por ondas.
- Planilla comparativa de presupuesto.

## Tecnologías

Planificación de proyectos, arquitectura de información y documentación.

## Estado de la muestra

Propuesta conceptual; no corresponde a un sitio implementado.

## Alcance y pendientes

Los costos son parte del documento de trabajo y no se presentan como cotizaciones verificadas. La ficha describe el trabajo de planificación, sin acreditar implementación o resultados de campaña.
