# Sitio de consultoría digital

Muestra de diseño de un sitio para presentar servicios de datos, cartografía y educación digital. Autoría: Gianina Jensen Guzmán.

El paquete original contiene páginas HTML, estilos CSS y demostraciones JavaScript. El código y los recursos de esta muestra se conservan fuera del repositorio público, pendientes de revisión de contenidos de ejemplo y separación de materiales privados.

Esta ficha documenta la línea de trabajo; no ofrece un servicio activo ni acredita modelos entrenados.
