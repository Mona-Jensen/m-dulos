# Visualizador territorial

Explorar perímetros, capas cartográficas y puntos de interés para presentar escenarios territoriales.

## Autoría

Proyecto creado y desarrollado individualmente por Gianina Jensen Guzmán.

## Qué incluye

Mapa interactivo, conversión UTM y controles de capas.

## Estado

Prototipo de demostración.

## Tecnologías

JavaScript, Leaflet, Proj4 y Node.js

## Ejecución

```text
npm run dev
Consultar en server.js el puerto configurado.
```

Las instrucciones se deducen de los archivos; no implican una ejecución validada en este entorno.

## Alcance y limitaciones

Las cifras de telemetría están escritas en la interfaz; no acreditan conexión a sensores. La procedencia y geometría de las coordenadas requieren revisión. No utilizar como herramienta operativa de emergencias.
